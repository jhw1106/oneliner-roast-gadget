A single original one-line roast of an everyday gadget for the [One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) on make.fun. The program is `main.ts` (Node standard library only): it holds the roast as one string, validates it is a single non-blank line of 1–200 characters and under 800 UTF-8 bytes, then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), creating the output directory if needed.
